# Regenerates requirements.txt from requirements.in. That file is generated output —
# never edit it by hand.
#
#   Add or change a package (keeps every other pin where it is):
#     uv pip compile requirements.in --universal --python-version 3.12 -o requirements.txt
#
#   Pull in security fixes (re-resolves everything to the newest allowed):
#     uv pip compile requirements.in --universal --python-version 3.12 --upgrade -o requirements.txt
#
# --python-version 3.12 is the server's interpreter. --universal is not cosmetic: without
# it the resolution is specific to the machine that ran it, and compiling on macOS ARM
# dropped greenlet — which SQLAlchemy requires on x86_64 — so the Linux server installed
# it unpinned, outside the lockfile and outside the CVE audit.
#
# pip-tools cannot do either of those (no cross-version, no cross-platform resolution),
# which is why this is uv and not pip-compile.
uv>=0.5

# CVE scan of the pinned dependencies. Deselected from the default run because it needs
